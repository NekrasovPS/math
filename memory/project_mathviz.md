MathViz is an interactive mathematics learning platform focused on geometry, algebra, and physics. The application features:

**Key Features:**
- Interactive 3D visualization of geometric figures using Three.js
- Structured lessons with theoretical content and exercises
- Progress tracking with Redux state management
- Dark/light theme switching
- Responsive design with Tailwind CSS

**Technology Stack:**
- React 19 with TypeScript
- Three.js via React Three Fiber
- Redux Toolkit for state management
- Tailwind CSS for styling
- Framer Motion for animations
- KaTeX for mathematical formulas

**Project Structure:**
- Modular component architecture
- Path aliases for clean imports (@, @components, @scenes, etc.)
- Lesson data stored in structured format
- 3D models and exercises configuration

**Development:**
- Vite build tool
- ESLint for code quality
- Strict TypeScript configuration
- Hot module replacement in development

**Current State:**
- Basic landing page with features overview
- Lesson listing page
- Individual lesson pages with 3D visualization
- Redux store for theme and progress tracking
- Placeholder pages for exercises and progress
- 3 geometry lessons implemented (cube, pyramid, cylinder)

The project is actively developed and ready for expansion with more lessons and interactive features.
